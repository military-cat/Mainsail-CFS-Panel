# CFSail attribution

CFSail is the project name of Mainsail-CFS-Panel.

The browser panel is derived from [swilsonnc/K2-plus-cfs-panel](https://github.com/swilsonnc/K2-plus-cfs-panel), with rewritten filament metadata handling, CFS and external-spool views, state synchronization, native layout integration and localization. This distribution's code is licensed under GPL-3.0-only; see LICENSE.

The wire format was cross-checked against CrealityPrint's device interface and [DaviBe92/k2-websocket-re](https://github.com/DaviBe92/k2-websocket-re). Material names and printer-reported error details are supplied by the printer and are not translated by CFSail.

The CFS product image is a user-supplied Creality product image. Its image rights remain with the respective rights holder; the code license does not grant ownership of that image.

Mainsail and Creality product names belong to their respective owners. CFSail is a community project and does not imply endorsement by those projects or manufacturers.
